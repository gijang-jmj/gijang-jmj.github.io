# Triptych 소개 사이트

[사이트 보기](https://gijang-jmj.github.io/)

macOS용 Triptych의 기능과 실제 앱 화면을 소개하는 정적 사이트입니다. 이 저장소에는 소개 페이지와 공개용 이미지 에셋만 포함됩니다. 앱 소스 코드, 실행 파일, Google API 키는 포함하지 않습니다. 앱의 공개 배포·라이선스 정책은 아직 결정되지 않았습니다.

## 로컬 보기

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

외부 라이브러리·분석 스크립트·빌드 도구가 필요하지 않습니다. GitHub Pages는 main 브랜치 루트에서 게시합니다.

## 이미지

Triptych 1.1.1 (4)의 실제 화면을 2026-10-25 촬영했습니다. 여행 사진은 이 소개를 위해 AI로 생성한 데모 이미지이며, 좌표는 기능 설명을 위한 예시입니다. 개인 미디어는 사용하지 않았습니다. 지도 출처 표기는 캡처에 유지하며 Google 및 지도 데이터 제공자의 권리는 각 제공자에게 있습니다.

2026-10-26: 지도 데모를28개 미디어·12곳 예시 위치로 확장했습니다. AI 사진2종을 반복 사용하여 군집과 개별 마커를 보여줍니다. 요약 메모·설명 박스·화면 그리기를 각각 독립 화면으로 소개합니다.
